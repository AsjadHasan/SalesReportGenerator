# SalesReportGenerator
 Ask a sales manager how many sales records to enter, then for each one ask for the salesperson, product, and amount. Print each salesperson's total sales, units sold per product, and who the top performer is.
<br>
Topics Covered:
<br>
1. input() — taking user input.
2. int() — converting input into an integer.
3. def — defining a function.
4. for loop — repeating the process for multiple sales records.
5. Dictionaries (dict) — storing sales totals and product counts.
6. if-else — checking whether a key already exists.
7. Dictionary updating — adding sales amounts and counting products.
8. max() — finding the salesperson with the highest total sales.
9. Dictionary key and value access — using sales_totals.get.
10. F-strings — formatting the top performer's report.
11. print() — displaying the final sales report.
